## Exercícios de apropriação

1\. Explique o que é uma interface.

É como um modelo que mostra quais métodos uma classe precisa ter para funcionar corretamente.

2\. Qual a diferença entre classe abstrata e interface?

A classe abstrata pode ter métodos já prontos, enquanto a interface apenas define quais métodos a classe deve criar.

3\. Por que interfaces ajudam no trabalho em equipe?

Porque todos seguem o mesmo padrão, deixando o código mais organizado e facilitando o trabalho de cada pessoa.

## Desafio profissional

1\. Como interfaces ajudam ele a entender o sistema mais rápido?

Elas mostram o que cada classe precisa ter, então o novo desenvolvedor consegue entender melhor como o sistema funciona.

2\. O que acontece se ele não seguir o contrato?

O código pode apresentar erros, porque a classe precisa ter todos os métodos que foram definidos na interface.
