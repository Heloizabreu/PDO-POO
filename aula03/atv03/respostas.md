# Exercícios de Apropriação

**1. O que é herança?**

Herança é quando uma classe filha recebe informações e métodos de uma classe principal, podendo aproveitar o que já existe nela.

**2. Qual a diferença entre private e protected?**

O `private` só pode ser usado dentro da própria classe. Já o `protected` também pode ser acessado pelas classes filhas.

**3. O que significa sobrescrever um método?**

É quando uma classe filha utiliza um método que já existe na classe mãe, mas modifica seu funcionamento.

# Desafio Profissional

**1. O código atual suporta essa mudança?**

Sim, porque é possível criar novas classes filhas sem precisar mudar o código que já existe.

**2. O que precisa ser feito?**

Criar uma nova classe chamada ClienteInternacional, que herda as informações e os métodos da classe Cliente.

**3. Onde entra o polimorfismo?**

O polimorfismo permite que diferentes classes usem o mesmo método, mas cada uma tenha um funcionamento diferente.
